# Miguel Design OS — Source Projects

## Goal

Extract my personal frontend/design taste from apps I already built and like.

This repo is not for copying one app.
It is for teaching future agents my design judgment across multiple products.

Future apps should have:
- project-specific visual identity
- strong hierarchy
- clear primary action
- polished components
- clear clickable vs passive distinction
- good spacing and composition
- progressive disclosure
- concise human copy
- responsive layouts
- modular Tailwind implementation
- no AI slop
- no generic dashboard garbage unless the product actually requires it

## Learning rules

Golden apps = taste evidence.

Case studies = feedback evidence.

Manual preferences = global principles.

Do not copy one app literally.
Abstract the design language and improve it.
