Use for landing/portfolio/marketing pages. Do not use as the primary skill for dashboards or dense product apps.

## Workflow

1. Declare the design read.
2. Set active dials.
3. If no direction is approved, create 3 directions and stop for Migi before implementation.
4. Choose concept spine after direction selection.
5. Define section jobs.
6. For generated references, create one horizontal image per section.
7. For each section, choose composition anchor, background mode, image role, CTA variation, and second-read moment.
8. Explore safe refined, artistic expressive, and unexpected high-character palettes.
9. Lock selected palette and typography across the page.
10. Vary section rhythm.
11. Run anti-AI-tell preflight before handoff.

## Stop Conditions

- generic left-text/right-image default
- no direction-options gate before an unapproved visual-heavy landing/portfolio build
- no palette exploration for artistic/cinematic/portfolio/landing direction
- repeated same-family sections
- Blogspot / content-template structure
- text-only page when images are needed
- unreadable generated references
- CTA path unclear
