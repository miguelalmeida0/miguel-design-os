# References

This collection contains 116 inspiration images plus historical project and failure evidence. The normal `references` command returns inspiration images, without approval or app categories.

Original assets and legacy paths are preserved. The `approved/inspiration/` directory name is historical storage metadata; it is not a verified global preference for every visible feature. Other `approved/` and `rejected/` screenshots are useful for targeted QA, excluded from normal inspiration results.

Recent user uploads and client material stay in the ignored personal profile. Do not copy them into this public repository.

Inspect exact images and assign a project-specific role before transferring their composition, hierarchy, scale, materials or imagery. Keep differences between contexts. Endorsing a reference does not confirm every feature. Repository notes are prior annotations whose human/inference provenance is not automatically verified.

Screenshots are evidence, not production assets. Do not infer interaction, animation or working behavior from a still. Preserve the explicit ban on handwritten typography even if a reference contains script lettering.
