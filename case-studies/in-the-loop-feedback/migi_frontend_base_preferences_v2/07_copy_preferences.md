# 07 — Copy Preferences

## Voice

Migi prefers copy that is:
- direct
- natural
- human
- short
- confident
- contextual

The tone should match the project. Do not force funny/social copy into serious tools.

## Avoid

- generic AI filler
- overly cute labels
- corporate jargon
- robotic form labels
- creepy profiling language
- repeated concept words
- overexplaining what the UI already shows

## Good patterns

### For consumer/social apps
```txt
Send this
Try again
Keep it simple
No pressure
Could be down
```

### For developer/productivity apps
```txt
Run check
Review changes
Open trace
Fix issue
Compare results
```

### For finance/research apps
```txt
View thesis
Open position
Compare exposure
Update watchlist
```

## Bad patterns

```txt
Here is the tiny move
Mia-shaped plan
Weakness
Danger
Bait
Configure invite
Submit event
```

## Rule

If copy sounds like an internal model or a prompt response, rewrite it.
