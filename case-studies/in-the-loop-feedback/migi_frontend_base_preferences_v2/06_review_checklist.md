# 06 — Review Checklist Before Completion

Run this before saying the frontend task is done.

## Product/UX

- [ ] Does the screen have one clear primary purpose?
- [ ] Is the primary action obvious within 2 seconds?
- [ ] Is unnecessary complexity hidden behind progressive disclosure?
- [ ] Is there any modal chain? If yes, remove it unless explicitly required.
- [ ] Does the page avoid dashboard/form energy when not appropriate?

## Visual hierarchy

- [ ] Is there a clear focal point?
- [ ] Are too many elements competing equally?
- [ ] Are there unnecessary containers or nested cards?
- [ ] Are there any giant empty surfaces that feel accidental?
- [ ] Does the composition feel intentional on desktop and mobile?

## Interaction clarity

- [ ] Can a user tell clickable vs non-clickable elements immediately?
- [ ] Are passive status tags visually distinct from buttons?
- [ ] Are filters/toggles visually distinct from metadata?
- [ ] Are selected states unmistakable?
- [ ] Are there hover/active/focus/disabled states?

## Buttons

- [ ] Is there one primary CTA per zone?
- [ ] Does the primary CTA feel premium and intentional?
- [ ] Are secondary and tertiary actions visually subordinate?
- [ ] Are desktop CTAs not awkwardly stretched?
- [ ] Are mobile CTAs thumb-friendly?

## Copy

- [ ] Is copy short and human?
- [ ] Is there repeated or redundant wording?
- [ ] Does any copy sound robotic, creepy, manipulative, or over-explained?
- [ ] Are labels user-facing, not internal data-model names?

## Color / accessibility

- [ ] Did you avoid forcing a fixed old palette onto this project?
- [ ] Are project-specific colors mapped to semantic tokens?
- [ ] Does all important text meet contrast expectations?
- [ ] Are status colors not the only indicator of meaning?

## Images / avatars

- [ ] Are images cropped intentionally?
- [ ] Are faces visible and not awkwardly cut?
- [ ] Are avatars stable and non-creepy?
- [ ] Are image borders/frames intentional, not accidental?

## Responsive

- [ ] Does the main action fit above the fold when required?
- [ ] Does the bottom nav avoid content collision?
- [ ] Does the desktop layout avoid feeling like stretched mobile?
- [ ] Does mobile avoid long form-like scrolling for fast tasks?

## Final judgement

- [ ] Would this look embarrassing next to a top-tier consumer app?
- [ ] Does it feel like a polished product rather than a prototype?
- [ ] Did you avoid AI slop?
