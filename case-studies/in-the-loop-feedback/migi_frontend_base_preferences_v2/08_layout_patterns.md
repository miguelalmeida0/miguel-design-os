# 08 — Preferred Layout Patterns

Use these as reusable layout instincts, not fixed templates.

## Pattern A — Focused Hero Interaction

Use when the screen has one main action.

Structure:
- compact header
- one dominant hero object
- primary action attached to hero
- secondary controls nearby
- details hidden

Good for:
- onboarding
- fast creation
- decision flows
- social/game-like flows

## Pattern B — Dense But Calm Workspace

Use when the screen is a technical or data tool.

Structure:
- clear header
- compact filters
- main working area
- details drawer/panel
- stable action bar

Good for:
- developer tools
- model evaluation tools
- research dashboards

Avoid turning this into container soup.

## Pattern C — Editorial / Portfolio Page

Use when selling a project or personal brand.

Structure:
- strong narrative hero
- proof sections
- selected details
- clear CTA
- polished typography

Avoid generic SaaS landing-page sections.

## Pattern D — Feed / Room / Chat Flow

Use when communication is the main action.

Structure:
- current truth / status compact
- message/update area dominant
- composer prominent
- quick replies close to composer
- details in drawers

Avoid side dashboards unless they are essential.

## Pattern E — Card Deck / Carousel

Use when the interaction is one item at a time.

Structure:
- one featured card
- next/previous peeks or reel
- immediate action
- shuffle/deal/next mechanic if relevant

Avoid turning the deck into a full grid.
